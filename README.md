# CTIS Security Roadmap

> Interactive learning roadmap for cybersecurity enthusiasts and professionals

A comprehensive, visual roadmap designed for the **CTIS (Cyber Threat Intelligence Specialist)** certification path and beyond. This project contains interactive mind maps and learning paths covering various cybersecurity domains.

## 🚀 Live Demo

Visit the site: **[https://onurcangnc.github.io/CTIS_Security_Roadmap](https://onurcangnc.github.io/CTIS_Security_Roadmap)**

## 📂 Usage

Simply clone the repository and open any HTML file in your browser:

```bash
git clone https://github.com/onurcangnc/CTIS_Security_Roadmap.git
cd CTIS_Security_Roadmap
```

Open `index.html` to start exploring.

## 🎯 Covered Topics

- **Active Directory** - Kerberos, LDAP, Privileged Access
- **Web Security** - OWASP Top 10, Bug Bounty, XSS, SQLi
- **Network Security** - Nmap, Burp Suite, Wireshark, Metasploit
- **Red Teaming** - C2 Frameworks, Lateral Movement, Persistence
- **Mobile Hacking** - Android/iOS penetration testing
- **WiFi Security** - WPA2/WPA3 cracking, Rogue AP attacks
- **AI Security** - LLM attacks, Prompt injection, Adversarial ML
- **Defensive Security** - SIEM, EDR, Threat Hunting, DFIR
